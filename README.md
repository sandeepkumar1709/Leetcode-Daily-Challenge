# 52-Day LeetCode Daily Challenge — Problem-Solving with Purpose

**Challenge:** Solve a LeetCode Daily Challenge every day  
**Goal:** Build consistency, deepen DSA mastery, and explain each solution  
**Completed:** 52 consecutive days of high-quality problem-solving

---

## Why I Built This

As a software engineer, I'm passionate about writing code that not only works but makes sense. This repository is a reflection of that mindset. Over 52 consecutive days, I tackled LeetCode's Daily Challenge and documented **every single solution** with:

- Clear explanation of my **approach**
- **Time** and **space** complexity analysis
- Code that tells a story, not just solves a problem

> “Anyone can write code. The challenge is to write code that is efficient, readable, and explains your thinking.”

---

## 🧩 Repo Structure

This repository is organized by date, matching the LeetCode Daily Challenge solved on that day.

```
📁 Leetcode-Daily-Challenge/
├── Feb_27_Maximum_Sum_With_Same_Digit_Sum.py
├── Feb_28_Some-Other-Problem.py
├── ...
└── README.md
```

Each file follows this structure:

- **Approach**: A plain-English breakdown of my logic
- **Complexity**: Time and space complexity clearly stated
- **Code**: Clean, tested Python code
- **Test Output**: Demonstrates correctness
